# bootcampsantander2025
Repositório para aprendizado de cybersegurança. 
Foi criado um ambiente controlado de testes com o Kali Linux e o Metasploitable2, destacando o compromisso com a ética, utilizando técnicas como escaneamento e enumeração de portas, usuários e serviços, ataques de força bruta utilizando técnicas como password spray, credencial stuffing, dentre outras e pude verificar os dois lados, tanto do atacante como do defensor, reforçando a importancia de utilizarmos senhas fortes e sempre alterar senhas padrões utilizadas em ambientes corporativos.
